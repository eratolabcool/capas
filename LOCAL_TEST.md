# CapasPro Local Test

## Requirements

- Node.js 20+
- npm

## Install

```bash
npm install
```

## Development server

```bash
npm run dev
```

Open the local Astro URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Environment variables

Create `.env`:

```env
RESEND_API_KEY=
QUOTE_EMAIL=
PUBLIC_WHATSAPP_NUMBER=
```
